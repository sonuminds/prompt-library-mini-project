## 1. LinkedIn Post Generator

### Use Case  
Used by professionals, students, and entrepreneurs to share personal stories, achievements, or insights on LinkedIn.

### Techniques Used  
- Role Prompting  
- Constraints  
- Contextual Anchoring  

### Actual Prompt  
You are a LinkedIn personal branding expert who writes posts that feel human, relatable, and thoughtful — not corporate or robotic.

Write a LinkedIn post for a final-year Computer Science student who has completed their first Machine Learning project (Diabetes Prediction using Pima Indians dataset).

Requirements:
- Start with a strong personal hook  
- Mention tech stack (Python, Pandas, Scikit-learn)  
- Include one challenge and solution  
- End with a call to action  
- Keep under 200 words  
- No emojis  
- Tone: Confident but humble  

### Output  
3 months ago, I had no idea what a confusion matrix was.

Today, I just submitted my first machine learning project — a Diabetes Prediction model built on the Pima Indians dataset.

Tech stack: Python, Pandas, Scikit-learn, Logistic Regression

The biggest challenge I faced was overfitting. My model kept giving inconsistent results, and I couldn’t figure out why. After debugging, I realized the issue was improper feature scaling. Once fixed, the model improved significantly.

This project taught me how important data preprocessing and understanding models really are.

I would appreciate feedback from anyone working in ML or health data.

#MachineLearning #Python #DataScience #StudentProject #BTP

Step 1: Basic prompt  
Step 2: Added details  
Step 3: Added structure and tone
